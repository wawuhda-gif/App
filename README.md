# ZiVPN UDP Android App

Aplikasi Android VPN ringan untuk ZiVPN UDP Protocol

## Fitur
- ✅ Koneksi VPN UDP
- ✅ Input Host/IP dan Password
- ✅ Penyimpanan Credentials Terenkripsi
- ✅ Status Koneksi Real-time
- ✅ Lightweight & Minimal UI
- ✅ Keep-alive Packet untuk Stabilitas

## Requirements
- Android 5.0+ (API 21)
- Android Studio
- Kotlin 1.8+

## Setup
1. Clone repository
2. Buka di Android Studio
3. Input Host/IP ZiVPN Anda
4. Input Password VPN Anda
5. Tap Connect

## Security
- Credentials disimpan dengan enkripsi menggunakan EncryptedSharedPreferences
- Tidak ada server logging
- Semua data lokal
